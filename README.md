# A股量化选股策略说明书

> 版本：v1.0 | 更新日期：2026-09-06

## 通用说明

### 基础过滤（所有策略均先执行）

- 剔除 ST / *ST / 退市股
- 剔除停牌（价格为 0 或空）
- 仅保留沪深主板 + 创业板 + 科创板

### 数据来源

| 指标类 | 来源 | 时间维度 | 缓存 |
|--------|------|---------|------|
| PE、PB、市值、现价、涨跌幅、换手率、振幅 | 腾讯实时行情 | **当日实时** | 5 分钟 |
| ROE、净利润增速、营收增速、毛利率 | 东方财富业绩报表 | **最新一期财报** | 24 小时 |

### 打分机制

`_safe_rank` 将指标在全市场百分位排名，映射为 0-100 分，缺失值取 50 分。

---

## 1. 低估值策略

**核心逻辑**：用当日低估值，筛选最新财报盈利为正的标的。

| 指标 | 条件 | 时间维度 |
|------|------|---------|
| PE | 0 < PE < 30 | 当日实时 |
| PB | 0 < PB < 5 | 当日实时 |
| ROE | > 0 | 最新财报 |
| 市值 | > 50 亿 | 当日实时 |

**打分权重**：PE(50%, 越低越好) + PB(30%, 越低越好) + ROE(20%, 越高越好)

**适配场景**：寻找被市场低估、但基本面不亏的中大盘股，偏价值风格。

---

## 2. 高成长策略

**核心逻辑**：用最新财报的高增速，配合合理估值。

| 指标 | 条件 | 时间维度 |
|------|------|---------|
| 营收增速 | > 20% | 最新财报 |
| 净利润增速 | > 20% | 最新财报 |
| PE | 0 < PE < 100 | 当日实时 |
| 市值 | > 30 亿 | 当日实时 |

**打分权重**：净利润增速(40%, 越高越好) + 营收增速(30%, 越高越好) + ROE(30%, 越高越好)

**适配场景**：捕捉业绩高速增长的成长股，容忍较高估值。

---

## 3. 质量策略

**核心逻辑**：只挑高 ROE + 高毛利的大市值优质公司。

| 指标 | 条件 | 时间维度 |
|------|------|---------|
| ROE | > 10% | 最新财报 |
| 毛利率 | > 20%（若有数据） | 最新财报 |
| 市值 | > 100 亿 | 当日实时 |

**打分权重**：ROE(100%, 越高越好)

**适配场景**：寻找盈利能力强、商业模式优的行业龙头，偏白马风格。

---

## 4. 小市值策略

**核心逻辑**：小市值 + 基本面不差，博取弹性。

| 指标 | 条件 | 时间维度 |
|------|------|---------|
| 市值 | 20 亿 < 市值 < 100 亿 | 当日实时 |
| PE | 0 < PE < 60 | 当日实时 |
| ROE | > 0（若有数据） | 最新财报 |

**打分权重**：市值(100%, 越小越好)

**适配场景**：寻找小盘股中的非亏损标的，弹性大但风险高。

---

## 5. 动量策略

**核心逻辑**：捕捉当日强势上涨、换手活跃的股票。

| 指标 | 条件 | 时间维度 |
|------|------|---------|
| 当日涨幅 | 0 < 涨幅 < 15% | 当日实时 |
| 换手率 | 1% < 换手 < 15% | 当日实时 |
| 市值 | > 30 亿 | 当日实时 |

**打分权重**：当日涨幅(50%, 越高越好) + 换手率(30%, 越高越好) + 振幅(20%, 越高越好)

**适配场景**：纯短线动量，追涨当日强势股，持仓周期短。

---

## 6. 多因子综合策略

**核心逻辑**：估值 + 质量 + 成长 + 动量 四维均衡打分。

| 指标 | 条件 | 时间维度 |
|------|------|---------|
| PE | 0 < PE < 80 | 当日实时 |
| PB | 0 < PB < 10 | 当日实时 |
| 市值 | > 30 亿 | 当日实时 |

**打分权重**：
- 估值分(30%)：PE(50%) + PB(50%)，越低越好
- 质量分(30%)：ROE 越高越好（缺失取 50 分）
- 成长分(20%)：净利润增速越高越好（缺失取 50 分）
- 动量分(20%)：优先用 60 日涨幅，否则用当日涨幅，越高越好

**适配场景**：均衡配置，避免单一因子暴露，适合作为通用选股基准。

---

## 时间维度总结

| 策略 | 主要时间维度 | 说明 |
|------|------------|------|
| 低估值 | 实时估值 + 财报盈利 | 混合 |
| 高成长 | 财报成长 + 实时估值 | 混合（偏财报） |
| 质量策略 | 财报盈利 | 纯财报（季度/年度） |
| 小市值 | 实时市值 + 实时估值 | 纯当日实时 |
| 动量策略 | 实时行情 | 纯当日实时 |
| 多因子综合 | 实时 + 财报 | 混合均衡 |

## 注意事项

1. **动量策略和多因子中的 60 日涨幅**（`pct_chg_60d`）当前数据中未实际计算（被置空），所以多因子的动量分实际回退到当日涨幅。如需 60 日动量，需要补充该字段的数据计算。
2. 所有策略输出前 30 只股票，按综合得分降序排列。
3. 策略筛选结果仅供研究参考，不构成投资建议。

QA:我要在那里选股的话，选得分最高就可以了吗
A:不是。选得分最高 ≠ 稳赚。 得分只是一个相对排名工具，不能直接当买入信号。

得分的真正含义
策略得分是在该策略因子维度上的全市场百分位排名（0-100分）。比如低估值策略得分90，意思是这只股票在"PE低+PB低+ROE正"这个维度上，比市场上90%的股票更符合"低估值"定义。

它衡量的是"像不像"，不是"涨不涨"。

为什么不能只看分数
风险	说明
价值陷阱	低估值策略选出的便宜股，可能是业绩持续下滑的"价值陷阱"，便宜有便宜的道理
追高风险	动量策略得分高 = 当日涨得多，可能已到短期高点，追进去就被套
数据滞后	ROE用的是最新财报（可能是3个月前的），期间基本面可能已恶化
市场风格	策略得分高不代表当前市场认这个风格，比如熊市里高ROE白马也会跌
只看单因子	低估值只看估值，忽略了技术面、资金面、消息面
更合理的使用方式
得分作为初筛，不是终选
用策略选出Top 30，缩小范围
再手动看K线、基本面、消息面做二次筛选
多策略交叉验证
同时出现在"低估值"和"质量策略"的股票，比只出现在一个策略里的更可靠
动量策略选出的，再看看估值是否合理
结合技术面择时
得分高但K线走坏的（破位、均线空头），先等等
得分高且处于上升趋势的，胜率更高
分批建仓，不梭哈单只
不要只买得分第1名那一只
可以选得分前5-10只分散配置
看得分的绝对值，不只看排名
得分90+和得分60+是有质的区别的
如果整个市场都不符合策略条件，得分会普遍偏低，这时不如空仓
简单建议
策略得分 = 缩小选股范围的工具，不是买入信号。

得分最高的那只，值得你重点研究，但在看K线、看基本面、看市场环境之前，别急着买。
